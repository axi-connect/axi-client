Lo que comparten

Una sola capa, seis caracteres

  • CapasDos: el elemento pone color base y grano, y ::before es la burbuja. Arriba no hay nada.
  • Se vaLa aurora que deriva 72 s en bucle, que era la única excepción de §6 en esta vista, y el dot-grid.
  • Se quedaEl grano tileado, el recorte del campo y el aislamiento: la decoración no puede pisar el rail.
  • Coste0 ms de JS, 0 animation, 0 filter sobre el árbol, 0 backdrop-filter nuevo. Pinta una vez.
  • ColorSolo --axi-violet, --axi-brand, --axi-amber y --foreground. Ni un hex nuevo.

La burbuja vive en el campo, no en el scroller: al bajar por un hilo largo se queda quieta donde está. Es lo que hace que el compositor se lea como la fuente de luz de la pantalla en vez de una caja pegada abajo, y por eso absorbe el resplandor que hoy lleva el compositor por separado.

Ficha por propuesta

Qué hace cada una y con qué CSS

A · Domo

La más luminosa
  • FormaElipse ancha con relleno violeta y un filo de 1,5 px. La cresta cae al 44 % de la altura, justo detrás del compositor.
  • CarácterUna tarima de luz bajo Axel. Es la que más presencia da y la que mejor casa con la sombra de contacto del avatar.
.axel-field::before {
  left: -28%; right: -28%; bottom: -56%; height: 112%;
  background-image:
    radial-gradient(closest-side,
      transparent 0 calc(100% - 1.5px),
      color-mix(in srgb, var(--axi-violet) 38%, transparent)
        calc(100% - 1.5px) 100%,
      transparent 100%),
    radial-gradient(closest-side,
      color-mix(in srgb, var(--axi-violet) 24%, transparent) 0%,
      color-mix(in srgb, var(--axi-violet) 10%, transparent) 44%,
      transparent 100%);
}

B · Filo

La más arquitectónica
  • FormaUn arco sin relleno: solo el borde de un círculo enorme, en tinta del texto, con un rubor violeta muy tenue por dentro.
  • CarácterUna bóveda dibujada, no iluminada. La que menos color mete y la que mejor aguanta un hilo largo encima.
.axel-field::before {
  left: -45%; right: -45%; bottom: -88%; height: 150%;
  background-image:
    radial-gradient(closest-side,
      transparent 0 calc(100% - 1.1px),
      color-mix(in srgb, var(--foreground) 24%, transparent)
        calc(100% - 1.1px) 100%,
      transparent 100%),
    radial-gradient(closest-side, transparent 0 56%,
      color-mix(in srgb, var(--axi-violet) 12%, transparent) 100%);
}

C · Horizonte

La más serena
  • FormaLa misma burbuja, pero mucho mayor que la pantalla: solo entra su casquete y cruza casi recta, como el horizonte de un planeta. Filo ámbar de 1,2 px.
  • CarácterEditorial y cálida. El ámbar del filo es el único sitio donde entra el color de energía de la marca.
.axel-field::before {
  left: -90%; right: -90%; bottom: -150%; height: 210%;
  background-image:
    radial-gradient(closest-side,
      transparent 0 calc(100% - 1.2px),
      color-mix(in srgb, var(--axi-amber) 48%, transparent)
        calc(100% - 1.2px) 100%,
      transparent 100%),
    radial-gradient(closest-side,
      color-mix(in srgb, var(--axi-brand) 17%, transparent) 0%,
      color-mix(in srgb, var(--axi-violet) 13%, transparent) 40%,
      transparent 100%);
}

D · Eco

La más distintiva
  • FormaTres arcos concéntricos: el interior violeta y nítido, los dos de afuera desvaneciéndose. Como la onda que deja una piedra en el agua, congelada.
  • CarácterEs la que más se recuerda. Da profundidad sin meter masa de color, así que el texto encima sigue limpio.
.axel-field::before {
  left: -60%; right: -60%; bottom: -110%; height: 180%;
  background-image:
    radial-gradient(closest-side, transparent 0 calc(100% - 1px),
      color-mix(in srgb, var(--foreground) 8%, transparent)
        calc(100% - 1px) 100%, transparent 100%),
    radial-gradient(closest-side, transparent 0 calc(86% - 1px),
      color-mix(in srgb, var(--foreground) 13%, transparent)
        calc(86% - 1px) 86%, transparent 86%),
    radial-gradient(closest-side, transparent 0 calc(72% - 1px),
      color-mix(in srgb, var(--axi-violet) 34%, transparent)
        calc(72% - 1px) 72%, transparent 72%),
    radial-gradient(closest-side,
      color-mix(in srgb, var(--axi-violet) 15%, transparent) 0%,
      transparent 72%);
}

E · Aura

La más silenciosa
  • FormaSin borde: dos resplandores encajados, uno ancho y otro más estrecho y brillante, los dos anclados al centro del borde inferior.
  • CarácterLuz sin contorno. No dibuja una burbuja, la insinúa. Es la más discreta de las seis y la que menos compite con el compositor.
.axel-field::before {           /* el halo ancho */
  left: -20%; right: -20%; bottom: -70%; height: 140%;
  background-image: radial-gradient(closest-side,
    color-mix(in srgb, var(--axi-violet) 22%, transparent) 0%,
    color-mix(in srgb, var(--axi-violet) 11%, transparent) 38%,
    color-mix(in srgb, var(--axi-violet) 3%, transparent) 70%,
    transparent 100%);
}
.axel-field::after {            /* el núcleo */
  left: 8%; right: 8%; bottom: -34%; height: 74%;
  background-image: radial-gradient(closest-side,
    color-mix(in srgb, var(--axi-violet) 26%, transparent) 0%,
    color-mix(in srgb, var(--axi-brand) 9%, transparent) 46%,
    transparent 100%);
}

F · Malla

La más rica
  • FormaLa burbuja recortada con máscara y, por dentro, tres focos de color: coral abajo a la izquierda, violeta abajo a la derecha y un ámbar tenue en la cresta.
  • CarácterLos tres colores de la marca en un solo objeto, contenidos por un borde limpio. La más cara de ver y la que más cuida el contraste del texto.
.axel-field::before {
  left: -34%; right: -34%; bottom: -62%; height: 124%;
  background-image:
    radial-gradient(closest-side, transparent 0 calc(100% - 1.4px),
      color-mix(in srgb, var(--axi-violet) 34%, transparent)
        calc(100% - 1.4px) 100%, transparent 100%),
    radial-gradient(58% 64% at 24% 86%,
      color-mix(in srgb, var(--axi-brand) 22%, transparent), transparent 72%),
    radial-gradient(60% 66% at 78% 92%,
      color-mix(in srgb, var(--axi-violet) 26%, transparent), transparent 72%),
    radial-gradient(70% 52% at 50% 26%,
      color-mix(in srgb, var(--axi-amber) 12%, transparent), transparent 76%);
  mask-image: radial-gradient(closest-side, #000 0 99.4%, transparent 100%);
}
